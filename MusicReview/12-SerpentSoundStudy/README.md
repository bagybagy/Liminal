# 海蛇曲と射撃SEの比較

同じ海蛇曲の約23秒、同じ5回の8連射、同じ拍位置・音量で比較します。
末尾には3音のボス撃破音を配置。実プレイ録音ではなく、Unityに取り込まれた
BGMと実際のゲームの音源生成処理を使うオフライン試聴ミックスです。

| ファイル | 内容 |
| --- | --- |
| A_Current | 現行。三和音を順に上昇し、オクターブを積み上げるFM音 |
| B_FoldedSameTone | 音色は現行のまま。根音・5度・3度の折り返しを使い、MIDI 60〜78の範囲に収める |
| C_FoldedSoftGlass | Bの音階に、柔らかい立ち上がり・控えめなFM倍音のガラス系射撃音を組み合わせる |
| C_EffectsOnly | CのSEだけ。BGMなしで音色とフレーズを確認する補助 |
| D_FadeBefore | TidalMemory→海蛇。従来の2拍・約1秒の直線フェード |
| E_FadeAfter | 同じ切り替えを8拍・約4秒の滑らかな等電力フェードに変更 |

まずAとCを比較し、音階変更だけが良ければBを確認してください。
B/Cの撃破音は既存のクリスタル音色を維持し、3音の順序だけ折り返します。
Cの各射撃音はBと同じ音高で積算エネルギーを合わせています。
各ミックスを個別に音量正規化したり、リミッターで押し上げたりはしていません。
ソース末尾の短いフェードは試聴ファイルのクリック防止で、ゲーム音源は変更しません。

## 採用境界

ゲームにはBGMのフェード改善だけを適用しています。B/CのSEは試聴用で未採用です。
TidalMemoryの音源・音階・射撃音は変更していません。
今回の比較は音階の上昇しすぎと音色の馴染みを判断するためのものです。
新曲の拍・小節頭・和声は前回の自動推定を使っています。
解析された和声の正しさや、曲固有の細かなグルーヴの修正まで完了したとは扱いません。

## 再生成

Unityの `Liminal/Export Serpent Audio Comparison`、またはバッチモードの
`-executeMethod Liminal.Editor.SerpentAudioStudy.Export` でWAVと数値レポートを生成します。
試聴用MP3はFFmpegのlibmp3lame・320kbpsで変換。WAVはローカルに保持し、
リポジトリにはMP3・レポート・生成処理を保存します。

等電力カーブは異なる音源間で中間の音量低下を抑えるための標準的な選択です。
曲の相関や和声によってはピーク増加や重なりが生じるため、聴感による確認が必要です。
[Audacity公式のクロスフェード解説](https://manual.audacityteam.org/man/fade_and_crossfade.html)
