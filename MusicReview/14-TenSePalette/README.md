# 10種類のSE / 海蛇曲との方向探し

ガラス系に絞った前回の案が合わなかったため、今回は録音された楽器と電子音を
混ぜて、音色の方向を広く探します。[番号と試聴リンク](INDEX.md)。

各候補は最初の約2秒がSE単体、その後が同じ海蛇曲と同じ8連射です。
全候補でBの折り返す音階・音域・発音時刻を共通にしています。
前回F/Gの1オクターブ上げは使用しません。ボス撃破音は含めません。
連続試聴は1〜10を同じ順番で繋いだものです。

ピアノ・グロッケン・マリンバ・チューブラーベル・ハープ・ピチカート・フルートは
CC0録音サンプル。電子鍵盤・デジタルプラック・水滴風の音は既存の試聴用
合成処理を再利用しています。厳密な楽器再現や実プレイ録音ではありません。
録音ソースの詳細は `Tools/se-audition-samples/SOURCES.md`、既存フルートは
`Tools/music-samples/SOURCES.md`。実際の楽器名はINDEXとレポートを優先します。

楽器ごとの録音頭の余白を除き、FFmpegの帯域制限付きリサンプリングで移調します。
音量は各音の積算エネルギーとピーク上限で寄せていますが、知覚音量の完全な
一致を保証するものではありません。BGMの音量は固定し、ミックス全体を
候補ごとに正規化・リミッター処理することはしていません。
音階・拍・和声は前回の推定タイムラインを使い、採譜の再検証は今回の範囲外です。

生成: `node Tools/audition-ten-se.mjs`。各候補と連続試聴は320kbps MP3。
WAVはローカルに保持し、MP3・レポート・生成コードをコミットします。
試聴作成時点ではゲームへ未採用。以下は、その後の採用判断です。

## 採用判断 / 2026-10-04

ユーザーが5番のハープを選択。海蛇曲の射撃・命中音に、同じ音色処理とBの
折り返し音階で採用します。TidalMemoryや他の曲、ボス撃破音は維持します。
10番の水滴風の音は、別曲での音色設計のベース候補として保管し、現時点では未採用です。
比較MP3・WAV・生成時レポートは選択前の履歴として残します。
ゲーム用ノートバンクの再生成は `node Tools/audition-ten-se.mjs --export-harp-bank`。
Windowsの開発ビルドを更新しますが、公開Releaseはv0.1.10のままです。
